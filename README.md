# Apple Music — Pantalla de reproducción en Jetpack Compose

Recreación de la pantalla de reproducción de Apple Music para Android, hecha con **Kotlin** y **Jetpack Compose** con fines educativos

Es mi **primer contacto con Kotlin y Compose**. Lo hice como actividad del ciclo de DAM (2º curso), viniendo de Java y de interfaces en XML, y como preparación para el proyecto final del ciclo, que desarrollaremos con estas tecnologías.

## Tecnologías

- Kotlin
- Jetpack Compose
- Android Studio
